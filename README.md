# Qual é a Boa?

Projeto acadêmico da disciplina **Startup Project One — ADS / FACENS**.

## Problema
Informações sobre eventos, bares, restaurantes, cafés, festas, atividades culturais e outras experiências locais ficam espalhadas entre diferentes canais, o que dificulta descobrir rapidamente o que fazer e aumenta o risco de encontrar informações desatualizadas.

## Solução
O **Qual é a Boa?** propõe uma plataforma web, com evolução futura para aplicativo móvel, que reúne opções próximas e oferece mapa/lista, filtros por contexto, detalhes de locais e eventos, favoritos, compartilhamento, check-ins, missões, recompensas, cupons e painel para parceiros.

## Proposta de valor
**Descobrir o que fazer hoje, perto de você, em um só lugar.**

## MVP previsto
- Cadastro e login
- Mapa e lista
- Filtros
- Detalhes de local/evento
- Favoritos e compartilhamento
- Painel básico de parceiros
- Check-in e gamificação leve

## Tecnologias previstas
- Front-end: React ou Next.js
- Back-end: Node.js
- Banco de dados: PostgreSQL/Supabase
- Integrações: API de mapas

## Estrutura do repositório
- `frontend/` — aplicação web
- `backend/` — API e regras de negócio
- `docs/` — documentação acadêmica e técnica
